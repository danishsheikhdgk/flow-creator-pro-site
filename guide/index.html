Quick start

You only need the unpacked extension folder and a signed-in Google Flow account.

Load the extensionOpen chrome://extensions, enable Developer mode, choose Load unpacked, then select the Flow Creator Pro folder.
Open a Flow projectGo to flow.google.com, sign in, and open an existing project or create a new one.
Open the side panelPin Flow Creator Pro from the browser extensions menu, then click its icon while the Flow project tab is active.
Run a small testStart with one short prompt. Confirm manual generation works in Flow before starting a longer batch.

Generation workflows

Available controls can change when Google updates Flow or when a selected model does not support an option.

Text → Video

Add one prompt per task, choose video settings, and let the queue submit them in order.

Frames → Video

Use a start image—or supported start and end frames—with a motion-focused prompt.

Ingredients → Video

Attach characters or other assets as ingredients. Clear filenames make automatic matching more reliable.

Text → Image

Create still images from prompt text. Keep subject, style, framing and lighting instructions explicit.

Image → Image

Transform or restyle an input image while describing what should change and what must remain consistent.

Agent automation

Uses Flow's available Agent controls. Enable it only when Agent mode is visible and working manually.

Reference media

Flow Creator Pro works with media that is already available to your Google Flow project.

Open Add ingredientsUse the plus button beside the prompt box to open Flow's media picker.
Filter or searchChoose Images, Videos or Characters and search using the visible asset filename.
Select the correct assetCheck the preview, then choose Add to prompt. Avoid duplicate or nearly identical filenames.

Tip: name files before upload—for example hero-front.png or forest-wide.jpg. Stable names make repeated projects easier to manage.

Troubleshooting

Button not found

Refresh the Flow page, reopen the project and reload the extension. A Google UI change can require a remote selector update.

Start button disabled

Confirm the prompt editor contains text and all required frames or ingredients have been selected.

Queue does not start

Submit one prompt manually first. Then verify the correct Flow tab is active and check Debug Logs.

Server/config error

Check your connection and retry. The extension needs its remote configuration service to receive current selectors.

Video download fails

Signed Google video URLs expire and may reject cross-origin requests. Retry from the original Flow project while signed in.

Layout looks narrow

Increase the browser side-panel width or zoom out one step. Avoid opening DevTools beside a very narrow panel.

Frequently asked questions

Is Flow Creator Pro a Google product?

No. It is an independent extension and is not affiliated with or endorsed by Google.

Does it bypass Flow limits?

No. Your Google account, model availability, credits, safety checks and generation limits still apply.

Why can controls stop working after a Flow update?

The extension interacts with visible Flow controls. If Google changes their structure, the remote selector configuration may need an update.

Should I begin with a large batch?

No. Test one prompt first, then a short batch. This makes configuration or account problems easier to spot.
